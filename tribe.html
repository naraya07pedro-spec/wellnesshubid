Tribe-Commit Protocol

Disiplin lo jangan sendirian.

Konsep ini menggabungkan komitmen, squad lokal, bukti harian, dan reward. Versi ini masih MVP gratis: belum ada transaksi uang asli, belum ada GPS asli, dan validasi bukti masih simulasi/manual.

Coba Simulasi Challenge Biasa
01

Commit

Pilih target dan set deposit disiplin simulasi.

02

Tribe

Masuk squad 5 orang berdasarkan area dan goal.

03

Proof

Upload bukti harian untuk validasi ringan.

04

Reward

Streak, poin, dan simulasi refund komitmen.

Catatan keras: sistem deposit uang asli jangan dijalankan sembarangan. Untuk MVP ini gue bikin sebagai simulasi komitmen dulu. Kalau nanti pakai uang real, lo perlu aturan refund tertulis, izin peserta, sistem pembayaran aman, dan pencatatan transparan supaya nggak jadi sumber komplain.

Kenapa fitur ini hidup?

Empat lapis anti-malas.

Kalori kasih arah. Challenge kasih aksi. Tribe-Commit kasih konsekuensi sosial dan progres yang terasa lebih nyata.

Skin in the game

User tidak cuma niat. Mereka memilih target dan nilai komitmen sebagai pengingat.

Squad lokal

User tidak jalan sendirian. Sistem membentuk squad kecil berdasarkan area dan goal.

Proof harian

User upload bukti olahraga, makanan, atau langkah. Di MVP ini validasi masih ringan.

Reward loop

Streak dan poin bikin progres terasa seperti game, bukan cuma kewajiban.
